# 本地Mesh评分

在项目根目录双击`启动质量评分.command`。保持终端运行并连接移动硬盘，访问 http://127.0.0.1:8765 。首次安装前端依赖：在本目录执行`npm ci --ignore-scripts`。

左侧参考Clean，右侧待评资产。拖动任意模型会同步视角；滚轮缩放，右键平移。按1～5评分，左右方向键切换。支持待复核、备注、未评分筛选、自动下一项和CSV导出。

多建筑入口由`serve_review_collection.py --root <V3根目录>`启动。页头选择建筑，URL的`dataset`参数可直接收藏某栋。服务启动时自动发现`assets/<建筑ID>/process_v2`下具备manifest、machine_scores和visual_patch_audit的完整数据集；新增建筑完成后重启入口即可加入菜单。每栋使用独立SQLite文件，原有单建筑评分原位保留。当前CSV只导出所选建筑，Patch与机器分也按所选建筑隔离。

本次新增校准建筑：B360381775901063A0（规整办公楼，2180面）、B354401777301063A0（狭长转角建筑，1386面）。从历史训练来源的12个候选中查看三视角初选，再完成六视角检查；Clean锚点仍待用户确认，不声称其完全无缺陷。分别生成50版本，每栋解码内容无重复，49个退化均检测到六视角变化。

分数写入数据版本根目录`review_scores.sqlite3`，每次修改另存history记录。分数绑定variant与content_digest；文件名前缀不会被当作评分，也不会自动改名。不同模型内容不能直接复用评分。导出的CSV包含未评分空值。

机器建议单独保存在`machine_scores.json`，由`prepare_review_machine_scores.py`使用已有六视角差异诊断生成，属于未经人工标定的启发式伪标签，不是MOS。页面分别展示机器、人工与训练采用分数。训练读取`/api/training-labels`或导出CSV中的`effective_scale`：人工非空优先，否则机器；`label_source`保留来源。`uncertain`独立保留，不暗中改变这一优先级。点击同分按钮也算人工确认；撤销人工分会恢复机器来源，并保留历史。

队列边界、双视图中线和评分区上沿可以拖动调整。模型概要可展开查看顶点数、面数、贴图数、版本与本地路径。

Patch显示下拉框支持原始纹理、16区域分区、全部/几何/纹理干预范围。范围显示中红色表示几何、黄色表示纹理、紫色表示两者。点击模型查看源Patch干预面积比例。两侧均显示当前样本的干预位置，删除的面只能在Clean侧看原位置。简化/变形后的面映射采用最近源面中心近似，并在页面提示；源Face掩膜不是感知质量真值，重叠UV造成的间接影响可能不在掩膜中。

评分卡位于待评模型右上角；底部保留紧凑的1～5按钮、备注、复核和导航。几何可视化叠层不会改变原始资产或评分。

页面只在127.0.0.1提供服务，Three.js依赖本地加载，模型不上传。页面用于三栋建筑的参考对照校准，不代表多人MOS实验。两侧沿用相同光照与颜色管理。
