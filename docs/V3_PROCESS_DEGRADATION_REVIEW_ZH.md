# V3真实过程退化优化记录

版本：process_v2；种子2026；只生成B355201752601063A0一栋校准建筑。

## 已实施

- 新模块`process_degradations.py`与新版独立生成器`build_v3_process_pilot.py`，历史实验管线不受影响。
- MeshLab纹理感知QEM替代最近面中心UV重投影；按材质处理并保护边界，保留共享顶点法向。
- 六视角审计发现自由最优点放置在重度简化时出现远离主体的尖长面，已禁用`optimalplacement`，并增加输出坐标不得超出输入包围盒的测试。只重建了受影响的7个QEM版本。
- 在共享位置拓扑上生成空间相关噪声、平滑，再映射回UV拆分顶点。
- 缺失面积按真实三角面面积计算；同一建筑四档使用固定种子和嵌套表面区域。噪声固定随机场，只变幅度；平滑固定区域，只变迭代数。
- 局部纹理缺失、配准重影、曝光变化均由表面区域映射到原生glTF UV；取消图集固定矩形与循环回卷。重影只使用同一掩膜内有效来源。
- 降采样实际保留低分辨率贴图，不再放大后附加模糊；JPEG保留实际编码文件。
- 顶点位置执行Draco编码—解码并保留码流。组合中的UV量化执行Draco二维属性场编码—解码；这不是完整的glTF Draco扩展封装，文件大小不得视为完整发布码率。
- 组合局部退化使用共同区域；孔洞与较大范围纹理失效使残存邻域仍受影响。
- 全量记录具体子机制、参数、生成等级、解码内容哈希、零面积面、源Face干预掩膜。
- 输出16个源Patch干预面积比例及六视角预览、RGB变化诊断；这些不是MOS或感知Patch质量真值。
- 新预览文件暂用`scale3_`占位，Clean为`scale5_`，Manifest明确标记`unreviewed_placeholder`，不能将其作为评分训练标签。

## 过程解释与边界

QEM、JPEG、降采样、Draco是实际处理步骤。缺失、噪声、重影、曝光不一致属于过程启发的近似模拟：当前未输入航摄影像、相机标定或原始影像归属，不能声称复现了真实摄影测量重建失败。曝光区域是表面区域代理，不能声称它等于原始影像纹理岛。

大类内本轮选定具体子机制：几何伪影为相关表面噪声，不声称生成漂浮碎片；纹理缺失为灰色无效填充，不声称生成真实遮挡物；纹理细节损失为发布降采样；纹理配准为局部投影重影。后续若引入子机制须单独记录并重新校准，不能暗中替换。

表面区域跨原模型不连通部件时使用最近部件继续扩展，因此目标面积是全局面积，不能保证始终单连通。共享/重叠UV可能使同一像素影响多个面，Face干预掩膜描述选定来源区域，不等价于所有实际受影响面的精确感知标签。

校准阶段可以检查四档趋势，但不能强迫感知分数严格单调。不同机制不保证都覆盖scale1；优先保持物理合理性，再由用户评分。

## 验证与可复现性

依赖通过`pip install '.[process-pilot]'`安装；PyMeshLab 2025.7.post1、DracoPy 2.0.0。

运行生成器时输出版本目录必须不存在，避免覆盖评分。失败批次保留归档。平铺评分目录是发布后的查看副本；不应直接在旧目录重建。

测试覆盖：嵌套面积区域、重复位置顶点同步、局部纹理边界、Draco索引保持、QEM材质/UV有效性，以及既有导出测试。
