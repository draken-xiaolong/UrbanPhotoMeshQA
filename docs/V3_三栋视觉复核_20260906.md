## 本轮发现的生成与兼容性问题

1. **纯色材质**：旧流程假设所有材质有贴图。修复为保留纯色材质参数，不绑定灰色占位贴图，不对不存在的贴图施加纹理退化。
2. **无UV纯色面**：读取器的NaN是无UV内部占位，不应写入glTF访问器或送入Draco。导出使用不参与着色的有限UV占位，纯色面使用几何QEM；有贴图的非法UV仍拒绝，不能掩盖真实数据错误。
3. **重复UV采样**：候选A有合法负UV并使用REPEAT。表面纹理掩膜改为绘制跨周期的三角形副本，而不是逐顶点取模；不支持的越界采样方式仍拒绝。
4. **QEM停滞/重复**：候选A的QEM level2/3/4解码内容一致，50个审阅位置只有48个独立版本；候选B的QEM level3/4重复，50个位置有49个独立版本。原建筑50个均独立，合计150个审阅位置、147个独立内容。明确标记重复，不通过额外噪声伪造差异，不当作独立正式样本。导出增加`duplicate_of`与`independent_sample`，后续正式导入必须排除重复。
5. **平滑真实性**：部分平滑样本出现明显熔化、长三角形拉扯，不能只称作“轻微平滑”。已按实际观感评低分并加`generation_realism_review`标记；本轮保留供用户核查，未静默改变已讨论的四档参数。正式数据集冻结前必须单独处理该机制。

因兼容问题中断的输出保存在相应建筑的`process_v2_incomplete_*_debug`或`interrupted_variants/`，不进入网页正式50条清单，可追溯恢复；并非已完成有效样本。
