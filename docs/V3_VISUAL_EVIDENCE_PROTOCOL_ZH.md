# V3离线视觉证据：开发补充规范 v2

本补充统一细节可见度，不改变五档语义，不把目标档当标签。当前仍为开发版，须完成三栋校准后冻结；不得依据Test/Blind模型结果修改。

- 全景：七个固定方向，512px；用于整体完整性、缺陷范围和整体可用性判断。
- 细节：同七方向原生1024px渲染（不是放大512px图片），以相同相机、材质、背景和光照比较。它提高纹理采样密度，并非真实相机近距离拍摄，不声称测量精度。
- 对选定开发校准建筑，其所有候选与Clean使用相同两层证据；不能只对未命中目标的样本放大观察。首次Clean筛选可先用1024px七视角，再查看对应原生单图，不只看缩略拼图。
- 先按匿名证据记录全景意见，再结合固定细节证据确认档位。细小像素差不自动降级；考虑可见性、范围和使用影响。不从最差局部直接推断整栋scale1。
- 看不到/遮挡的面保持未知；技术失败、渲染缺陷与资产缺陷分开。离线证据不等于交互式全表面检查。
- 更高分辨率引起判断变化时另存v2评分及理由，保留旧评分，不静默覆盖。不把带目标知情的开发意见写成严格盲评。
- 记录内容digest、渲染版本、尺寸、方向、图片哈希和评分来源。人类有效分优先；AI意见不称人工MOS。
- GPU顺序渲染并清理每资产的纹理内存缓存；证据写外置盘/远端数据区后同步。不启动网页或一次加载三维网格页面。

本规范尚未为所有现有候选补齐1024px证据；正式评分冻结前要报告完整性与缺失，不能把仅有512px的旧结果当成已按v2复核。
